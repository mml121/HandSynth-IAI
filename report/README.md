# Report

IEEE conference paper for the HandSynth project.

## Building

### Option 1: Overleaf (Recommended)
1. Upload the entire `report/` folder to Overleaf
2. Set `main.tex` as the main document
3. Add your figure images to `figures/`
4. Compile with pdfLaTeX

### Option 2: Local build
```bash
cd report
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```
